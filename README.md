# minipay — учебный хост авторизации карточных операций на C

Мини-версия того, чем занимается процессинговый центр: принимает от терминалов
сообщения **ISO 8583** по TCP, проверяет карту и баланс, списывает деньги,
отвечает кодом ответа и умеет отменять операции (reversal).

Что внутри и чему учит:

| Модуль | Что делает | Темы C |
|---|---|---|
| `luhn.c` | проверка PAN по Луну, маскирование | строки, `char` как число, циклы с `size_t` |
| `iso8583.c` | упаковка/разбор сообщений, битовые карты | битовые операции, безопасный парсинг, владение памятью, `va_list` |
| `accounts.c` | хеш-таблица счетов, загрузка CSV | структуры, связные списки, `malloc/free`, opaque-типы, `strtoll` |
| `journal.c` | журнал операций для отмен и дублей | динамический массив, `realloc` |
| `processor.c` | бизнес-логика, коды ответа | мьютексы, инварианты, указатели на функции |
| `net.c` | TCP, фрейминг с 2-байтовой длиной | сокеты, частичные чтения, `EINTR`, порядок байт |
| `threadpool.c` | пул потоков с ограниченной очередью | `pthread`, условные переменные, производитель-потребитель |
| `server_main.c` | сервер: `poll` + `accept` + пул | сигналы, `atomic`, `goto cleanup`, `getopt` |
| `client_main.c` | эмулятор терминала | CLI, формирование сообщений |
| `tests/test_main.c` | 1241 проверка | макросы, `socketpair`, конкурентный тест |

## Сборка и запуск (Linux, gcc или clang)

```sh
make            # bin/minipay-server, bin/minipay-cli
make test       # юнит-тесты
make asan       # тесты под AddressSanitizer + UBSan
make tsan       # тесты под ThreadSanitizer
make valgrind   # тесты под valgrind (нужен пакет valgrind)
make demo       # сервер + сценарий терминала
```

Вручную, в двух терминалах:

```sh
./bin/minipay-server -f data/cards.csv -p 8583 -t 4
./bin/minipay-cli echo
./bin/minipay-cli balance 4111111111111111 2812
./bin/minipay-cli auth 4111111111111111 2812 150000      # 1500.00 RUB
./bin/minipay-cli -v auth 5555555555554444 2706 100      # -v печатает поля
```

Ctrl+C останавливает сервер штатно: он дорабатывает очередь, печатает
статистику и итоговые балансы.

## Протокол

Каждое сообщение передаётся как `[длина: 2 байта big-endian][ISO 8583]`.
ISO 8583 упрощён: все поля ASCII, битовая карта — 8 или 16 байт в двоичном виде.

| MTI | Операция | Обязательные поля |
|---|---|---|
| 0100 → 0110 | авторизация (покупка `000000`, баланс `310000`) | 2, 3, 4, 7, 11, 14, 41 |
| 0200 → 0210 | финансовая операция | как у 0100 |
| 0400 → 0410 | отмена | 2, 4, 11, 41, 90 |
| 0800 → 0810 | сетевое управление (`301` = эхо) | 70 |

Коды ответа: `00` одобрено, `05` отказ, `12` неверная операция, `13` неверная
сумма, `14` неверная карта, `25` исходная операция не найдена, `30` ошибка
формата, `51` недостаточно средств, `54` карта просрочена, `62` карта
ограничена, `94` дубль, `96` системная ошибка.

## Ограничения (это материал для упражнений)

Всё хранится в памяти; один глобальный мьютекс; только IPv4; нет PIN, MAC,
EMV, клиринга; поля только ASCII (в реальных сетях часто BCD и EBCDIC).
